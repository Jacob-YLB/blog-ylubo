# 1. 切换到源码分支
```bash
git checkout source
git pull origin source
```
# 2. 写文章，本地预览
```bash
npx hexo new "博客发布流程"
npx hexo clean && npx hexo g && npx hexo s
# npx hexo clean
# npx hexo generate
# npx hexo server
```

# 3. 提交源码
```bash
git add .
```
# 4. 提交备注，建议写清楚改动内容，方便以后回滚
```bash
git commit -m "xxxx"
```
# 5. 推送到远端仓库备份
```bash
git push origin source
```
# 6. 生成静态网页并自动推送到 main 分支
```bash
npx hexo clean && npx hexo g && npx hexo d
```
